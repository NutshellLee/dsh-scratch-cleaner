# 变更记录

## 发布的规矩

发布一个新版本号，只因为**运行时行为、对外接口或安装方式**发生了变化。纯文档改动、注释改动、测试补充都不单独发版；它们跟下一次真正的改动一起发。

理由写在明处：版本号是公开的，每个号都有人可能去锁定；只为改一段说明就占用一个号，会让版本列表看起来嘈杂，也让使用者的依赖升级白跑一趟。

行为未变：仍然只清理所配置的目录，仍然在 `turn/end` 执行，仍然跳过没有工作目录的会话。
